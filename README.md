## 🚀 What I'm building right now

### ✈️ Timeliner — Travel diary app

> *Your journeys, beautifully remembered.*

A cinematic, offline-first travel diary for Android and iOS. Log every stop, split expenses with your group, explore where you've been — in 20 languages.

<p>
  <img src="https://img.shields.io/badge/React%20Native-20232A?style=flat-square&logo=react&logoColor=61DAFB">
  <img src="https://img.shields.io/badge/Expo%20SDK%2055-4630EB?style=flat-square&logo=expo&logoColor=white">
  <img src="https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white">
  <img src="https://img.shields.io/badge/i18n%2020%20languages-C41E3A?style=flat-square">
  <img src="https://img.shields.io/badge/status-pre--launch-F59E0B?style=flat-square">
</p>

```
What's inside:
  ✅ Zigzag timeline with member attribution
  ✅ Collaborative trips — invite codes + guest members
  ✅ Stop-level expenses + group balances
  ✅ 20-language i18n (auto-detect from device)
  ✅ Offline-first — AsyncStorage + Supabase sync
  ✅ Photo viewer with pinch-to-zoom + download
  ✅ Location autocomplete (Nominatim / OpenStreetMap)
  ✅ Responsive layout — phone · tablet · iPad
  ✅ AI trip planner (Samaritan-powered, feature-flagged)
  ⏳ Play Store launch
  ⏳ App Store launch
```

### 🤖 Samaritan — AI travel orchestration

> *One prompt. A complete itinerary.*

A Java/Spring Boot AI backend that generates complete travel itineraries from a single natural language prompt. Powers the AI planner inside Timeliner. Send a destination, budget, duration, and preferences — get back a full day-by-day itinerary with GPS coordinates, estimated costs, and local tips.

<p>
  <img src="https://img.shields.io/badge/Java%2017-ED8B00?style=flat-square&logo=java&logoColor=white">
  <img src="https://img.shields.io/badge/Spring%20Boot%203.4-6DB33F?style=flat-square&logo=springboot&logoColor=white">
  <img src="https://img.shields.io/badge/Groq%20LLM-black?style=flat-square">
  <img src="https://img.shields.io/badge/PostgreSQL-4479A1?style=flat-square&logo=postgresql&logoColor=white">
  <img src="https://img.shields.io/badge/status-local%20→%20Railway-F59E0B?style=flat-square">
</p>

```
What's inside:
  ✅ REST API — single endpoint, structured JSON response
  ✅ Groq integration (llama-3.3-70b-versatile)
  ✅ Rate limiting — 20 req/min per API key
  ✅ Bearer token auth + prompt injection protection
  ✅ Integrated with Timeliner mobile app
  ⏳ Railway production deployment
  ⏳ Supabase Edge Function proxy
```

🔗 [View repo →](https://github.com/Abran7411/samaritan)
